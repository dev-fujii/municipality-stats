# municipality-stats

e-Stat の統計と気象庁の平年値を取り込み、市区町村ごとの静的な HTML を書き出す Go のライブラリを作ります。
動かせる見本のコマンドと `example/` も置く予定です。

作り始めの段階です。まず4県を対象にします。Go のコードはまだありません。

## 手元での確認

Go のコードを追加したら、リポジトリのルートで実行します。コードがない間は、パッケージが見つからない旨の出力になることがあります。

```sh
go vet ./...
golangci-lint run
go test ./...
```

データの出典は e-Stat と気象庁です。出典の正式な書き方はあとで足します。
